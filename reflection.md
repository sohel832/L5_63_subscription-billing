# Reflection — Static Code Analysis

### 1. What did you learn from static code analysis?
I learned that static code analysis helps identify coding errors, code quality problems, and potential security vulnerabilities without executing the program. Tools like Pylint, Flake8, and Bandit help improve code readability, maintainability, and security.

### 2. What were the major issues found in your program?
The major issues included unused imports, missing docstrings, incorrect formatting, long lines, deprecated AES encryption usage, hardcoded secrets, and weak random number generation. Some logical issues were also identified during code review, such as payment retry limits and coupon discount validation.

### 3. How did you fix the identified issues?
I removed unused imports, improved code formatting, added documentation, and corrected coding style violations. I migrated AES encryption to the cryptography library, used the secrets module for secure coupon generation, loaded the webhook secret from an environment variable, and used hmac.compare_digest() for webhook verification. I also added validation for coupon discounts, refunds, and payment retries.

### 4. Which tool was most useful and why?
Bandit was useful for identifying potential security vulnerabilities in the Python program. Pylint helped improve code quality, while Flake8 identified formatting and style issues. Using all three tools provided a more complete analysis.

### 5. What challenges did you face during the activity?
I faced challenges understanding the warnings generated by the analysis tools and deciding how to fix them without affecting the program's functionality. I also had to update the encryption implementation and configure the webhook secret using an environment variable.

### 6. What was the final result?
After applying the fixes, I executed the program and verified its output. The program ran successfully, and the final Bandit scan reported no issues identified. This activity helped me understand the importance of regularly checking code quality and security.

### 7. What did you learn about secure coding?
I learned that secure coding involves validating inputs, protecting secrets, using appropriate cryptographic libraries, generating secure random values, and verifying digital signatures safely. Static analysis is helpful, but it does not guarantee that a program is completely free of bugs or security vulnerabilities.
